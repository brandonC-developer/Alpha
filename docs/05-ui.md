# Interfaz

La interfaz sigue los mockups de [`docs/mockups/`](mockups/) ([ver el canvas](https://claude.ai/artifact/7SNJzNUbZrM38kJ7VhCAd7); copia local en `mockups/index.html`). Si el canvas y la copia local difieren, gana el canvas y Claude actualiza la copia. Este documento fija los valores que React debe usar y los estados que los mockups no muestran. La referencia visual de partida es `HXqFtqPXgAAf9KE.jpg`.

## 1. Sistema visual

Tema **oscuro por defecto** (como la referencia), con tema claro opcional. Variables CSS para `app/src/styles.css`:

```css
:root, [data-theme="dark"] {
  --bg: #0B0C0E;          /* fondo */
  --surface: #141518;     /* tarjetas */
  --surface-2: #1C1E22;   /* cabeceras, chips, hover */
  --border: #26282D;
  --ink: #F2F3F5;         /* texto principal */
  --muted: #9BA1AB;       /* texto secundario: contraste ≥ 7:1 sobre --surface */
  --faint: #6B717B;       /* ejes y leyendas */
  --accent: #4C9AFF;      /* salida, acción, enlaces */
  --input: #5A5E66;       /* barras de entrada */
  --good: #3FB950; --good-soft: rgba(63,185,80,.14);
  --warn: #E3A33B; --warn-soft: rgba(227,163,59,.14);
  --bad:  #F2555A; --bad-soft:  rgba(242,85,90,.14);
  --anthropic: #D97757; --google: #4C8DF6; --deepseek: #4D6BFE; --local: #9AA0A6; --other: #B583F2;
  --heat-0: #1A1C20; --heat-1: #34373D; --heat-2: #5C6068; --heat-3: #A3A7AE; --heat-4: #EDEEF0;
  --radius: 14px; --radius-sm: 8px;
  --font: Inter, "Segoe UI Variable", "Segoe UI", system-ui, sans-serif;
  --font-num: "Inter", system-ui, sans-serif;   /* con font-variant-numeric: tabular-nums */
}
[data-theme="light"] {
  --bg: #F6F7F9; --surface: #FFFFFF; --surface-2: #F0F2F5; --border: #DDE1E6;
  --ink: #15181D; --muted: #4B5563; --faint: #6B7280; --accent: #1D5FD1; --input: #9AA1AB;
  --heat-0: #EEF0F3; --heat-1: #D5D9DF; --heat-2: #A9B0BA; --heat-3: #5F6772; --heat-4: #15181D;
}
```

- **Tipografía:** cifras grandes de KPI a 44 px peso 500 con `tabular-nums`; etiquetas de sección en mayúsculas 13 px con `letter-spacing: .06em` y color `--muted`; texto base 14 px.
- **Espaciado:** múltiplos de 4; tarjetas con 20–24 px de relleno; 24 px entre bloques.
- **Diseño:** barra lateral de 220 px + contenido fluido con ancho máximo de 1440 px. Por debajo de 1100 px la cuadrícula de KPIs pasa de 4 a 2 columnas y los bloques de dos columnas se apilan.
- **Color con significado:** verde = variación positiva o dentro del límite; naranja = ≥ 80 %; rojo = ≥ 95 % o error; azul = salida y acciones. Cada proveedor tiene su color (`--anthropic`, `--google`…). Nunca solo color: siempre texto o icono al lado.
- **Real frente a equivalente API:** barras sólidas para coste real; barras rayadas (`decal` de ECharts) para equivalente API. Leyenda siempre visible.
- **Fuentes:** locales del sistema (Segoe UI Variable); Inter solo si está instalada. Sin fuentes remotas (la CSP no lo permite).

## 2. Navegación

Barra lateral, en este orden: Panel `/` · Costes `/costes` · Planes `/planes` · Sesiones `/sesiones` · Fuentes `/fuentes` · Ajustes `/ajustes`. Pie de la barra: mini estado de las ventanas de 5 h (`get_today_summary`) y «Actualizado hace N s».

Atajos de teclado: `Ctrl+1…6` cambian de pantalla; `R` = reescanear; `7`, `3`, `9`, `T` = rango 7 / 30 / 90 días / Todo en Panel, Costes y Sesiones; `Esc` cierra el desglose de sesión.

## 3. Pantallas

| Pantalla | Mockup | Datos | Interacciones clave |
| --- | --- | --- | --- |
| Panel | `Panel.html` | `get_dashboard` | Rango 7/30/90/Todo; clic en un agente o un modelo filtra; «Quitar filtro» |
| Costes | `Costes.html` | `get_costs` | Rango; alternar «Real», «Equivalente API» o ambos; enlace a precios para modelos sin precio |
| Planes | `Planes.html` | `get_plans`, `calibrate_plan`, `update_plan` | «Calibrar» abre un diálogo con un campo % y el texto de dónde mirarlo; editar cuota y presupuesto |
| Sesiones | `Sesiones.html` | `get_sessions`, `get_session_detail` | Ordenar por columna; filtro «solo anómalas»; clic → panel lateral con las llamadas |
| Fuentes | `Fuentes.html` | `get_sources`, `rescan` | «Reescanear»; lista de errores con archivo y línea |
| Ajustes | `Ajustes.html` | `get_settings`, `get_prices`, `upsert_price`, `get_recalc_log`, `set_deepseek_key`, `export_data`, `import_data` | Secciones: General, Precios, Alertas, DeepSeek, Datos |

**Textos fijos que se copian literalmente:**

- Costes, aviso bajo los KPIs: «El equivalente API es una referencia: con tu suscripción no pagas por token».
- Planes, bajo cada suscripción: «No incluye lo que uses en la web o la app móvil (claude.ai, Gemini), que comparten este límite».
- Planes, diálogo de calibración de Claude Pro: «En Claude Code escribe `/usage` y copia el porcentaje de la sesión actual». De Google AI Pro: «En Antigravity abre el selector de modelo › View Usage y copia el porcentaje».
- Planes, sin calibrar: «Sin calibrar: se muestra el consumo, pero no el porcentaje».
- Costes, sin precio: «N llamadas sin precio» + enlace «Añadir precio».

## 4. Estados obligatorios

| Estado | Comportamiento |
| --- | --- |
| Primera ejecución | Pantalla de bienvenida con las fuentes detectadas y una barra de progreso con `ingest-progress`; al terminar, Panel |
| Cargando | Esqueletos grises con la forma del bloque; nunca un spinner a pantalla completa |
| Vacío | «Aún no hay uso registrado en este rango» + botón «Ver todo» |
| Fuente no encontrada | En Fuentes: «No se encontró .gemini\antigravity\brain. ¿Está instalado Antigravity?» |
| Error de comando | Banda roja arriba con `CommandError.message` y botón «Reintentar» |
| Filtro activo | Chip «Antigravity ×» bajo el título; `Esc` o la × lo quitan |
| Sin red (DeepSeek) | Saldo «—» con el texto del error `http`; el resto funciona |

## 5. Accesibilidad

- Todo usable con teclado; foco visible (anillo de 2 px `--accent`).
- Los gráficos tienen `aria-label` con un resumen («Tokens por día: máximo 1,3 B el 2 de noviembre») y una tabla equivalente oculta para lectores de pantalla.
- Barras de plan con `role="progressbar"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`.
- Contraste AA como mínimo; las cifras grandes, AAA.
- Respeta `prefers-reduced-motion` (sin animaciones de ECharts).

## 6. Bandeja del sistema

- **Icono:** el logotipo con un arco que se llena según el % mayor de las ventanas de 5 h; gris sin calibrar, naranja ≥ 80 %, rojo ≥ 95 %.
- **Tooltip:** «Gestor de Tokens · hoy 4,2 M tokens · 1,84 $ equiv.».
